# Changelog

## v0.88.0 (2026-09-14)

- First public BooruFlow release for local management of works, characters, styles, Prompt Tags, models, LoRAs, artist prompt strings, and ComfyUI resources.
- Added native Windows and macOS scripts for installation, checks, lifecycle, update, backup, restore, export, packing, and one-time import.
- Added empty-database package import requiring Embedding and Reranker configuration, synchronous 1,024-dimensional vectors, and full-batch rollback on failure.
- Added complete Simplified Chinese, English, Japanese, and Spanish documentation and GitHub templates.

See the [v0.88.0 release](https://github.com/fzfz/booruflow/releases/tag/v0.88.0). BooruFlow uses the repository [MIT License](../../LICENSE).
