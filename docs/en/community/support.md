# Support

Run the platform `check` and `status` scripts, follow [Troubleshooting](../user/troubleshooting.md), and search [existing issues](https://github.com/fzfz/booruflow/issues). Add your version and reproduction difference to an existing matching issue.

For a new issue, choose support or bug. Provide BooruFlow version, OS and CPU, installation method, goal, exact blocked step, command or page, actual output, checks attempted, and minimal reproducing data. Replace API keys, ComfyUI credentials, personal paths, and private content with examples.

Maintainers reproduce and assess the evidence first. A request for information lists exact missing items; after the reporter supplies them, the issue is reassessed. A solution states the applicable version or steps, and the reporter retests. Maintainers close with a reason after a verified fix, a long-standing lack of required evidence, or a scope decision.
