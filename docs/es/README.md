# Documentación de BooruFlow

[简体中文](../zh-CN/README.md) · [English](../en/README.md) · [日本語](../ja/README.md) · [Español](README.md)

BooruFlow es un espacio local para gestionar obras, personajes, estilos, Prompt Tags, modelos, LoRA, cadenas de artistas y recursos de ComfyUI. La interfaz actual de la aplicación está en chino.
