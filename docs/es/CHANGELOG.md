# Registro de cambios

## v0.88.0 (2026-09-14)

- Primera publicación de BooruFlow para obras, personajes, estilos, Prompt Tags, modelos, LoRA, cadenas de artistas y ComfyUI.
- Scripts nativos Windows/macOS para instalar, comprobar, operar, actualizar, respaldar, restaurar, exportar, empaquetar e importar una vez.
- Importación a base vacía con Embedding/Reranker obligatorios, vectores síncronos de 1.024 dimensiones y rollback completo.
- Documentación y plantillas completas en chino simplificado, inglés, japonés y español.

Consulta la [versión v0.88.0](https://github.com/fzfz/booruflow/releases/tag/v0.88.0) y la [licencia MIT](../../LICENSE).
