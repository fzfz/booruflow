# Pull Requests

Describe problema, conducta final, Issue, alcance, comandos y resultados. Incluye capturas reales para UI y actualiza cuatro idiomas si cambia configuración, estructura o uso. Puede usarse cualquier idioma admitido.

Resuelve primero la automatización. Los mantenedores revisan alcance, objetivo y evidencia antes de implementación. Conducta nueva cubre ramas normal, error y límite; Schema, OpenAPI, errores, migraciones y scripts pasan controles correspondientes. Responde con commits y resultado repetido.

Para merge: alcance claro, contratos cumplidos, pruebas requeridas correctas, docs sincronizadas, capturas/evidencia y comentarios resueltos. El mantenedor enumera carencias y el autor vuelve a solicitar revisión tras completarlas.
