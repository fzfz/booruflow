# Flujo de Issues

Hay plantillas de bug, soporte y función en cuatro idiomas. Bug exige versión, arquitectura, instalación, reproducción, esperado/real, salida y ejemplo. Soporte exige objetivo, paso y comprobaciones. Función exige caso, conducta deseada y carencia actual. Sustituye secretos y rutas personales.

Estados: **pendiente de clasificación** hasta decidir tipo; **esperando información** hasta recibir datos; **confirmado** cuando se reproduce o evalúa; **en curso** con responsable y trabajo; **resuelto/cerrado** con versión o pasos confirmados, o motivo de duplicado, fuera de alcance o no reproducible.

Cada pregunta enumera vacíos y se reevalúa tras respuesta. Un PR de corrección enlaza el Issue; tras merge o solución ejecutable se registra versión y verificación antes de cerrar.
