# Soporte

Ejecuta `check` y `status`, sigue [Solución de problemas](../user/troubleshooting.md) y busca [Issues existentes](https://github.com/fzfz/booruflow/issues). En uno igual añade versión y diferencia de reproducción.

Para uno nuevo elige soporte o bug. Incluye versión, SO/CPU, instalación, objetivo, paso bloqueado, comando o página, salida real, comprobaciones y datos mínimos. Sustituye claves, credenciales ComfyUI, rutas y contenido privado por ejemplos.

Los mantenedores reproducen y evalúan. Si falta información enumeran campos; tras aportarlos reevalúan. Una solución indica versión o pasos y el autor vuelve a probar. Se cierra con motivo tras confirmar arreglo, ausencia prolongada de datos necesarios o decisión de alcance.
