# 发布

维护者使用语义版本号和带 `v` 前缀的 Git 标签。发布事实由 `config/release/` 的结构化配置定义，安装脚本、更新源、README 下载链接和 Release 附件读取同一来源。

发布前更新包版本与四语变更记录，确认迁移和恢复边界，运行合同、单元、集成、e2e、文档链接及平台脚本检查。只声明实际验证过的 Windows/macOS 架构。标签版本、包版本、数据库支持范围和数据包格式必须一致。

GitHub Release 附加可单独下载的 `install.bat` 与 `install.sh`，并提供四语发行说明、安装入口、已验证平台和恢复链接。发布后从公开地址 fresh clone，验证附件下载、安装、配置、启动、状态、停止，以及同版本数据导出和空库导入。

更新失败时保留发布前备份和旧版本标识；恢复流程还原匹配的代码、数据库、媒体和配置。确认恢复后再处理标签或修复版本。v0.88.0 是新公开仓库的首个版本，历史源仓库过程记录不属于公开变更历史。
