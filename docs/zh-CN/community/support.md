# 获取帮助

先运行平台 `check` 和 `status` 脚本，按[排错指南](../user/troubleshooting.md)处理对应症状，再搜索 [现有 Issues](https://github.com/fzfz/booruflow/issues)。找到同一问题时补充你的版本与复现差异。

新问题请选择使用求助或 Bug 模板。准备 BooruFlow 版本、操作系统与 CPU、安装方式、目标、卡住的具体步骤、完整命令或页面、实际输出、已尝试检查，以及能复现问题的最小数据。使用示例值替换 API 密钥、ComfyUI 凭据、个人路径和私人内容。

维护者会先复现并确认材料；缺少信息时会列出需要补充的项目。提交者补充后，维护者重新判断状态。解决方案应写明适用版本或操作步骤；提交者按步骤复测并确认结果。可复现问题已修复、问题无法复现且材料长期不足、或请求超出项目范围时，维护者写明理由后关闭。
