# Issue 处理规范

仓库提供 Bug、使用求助和功能建议三类四语模板。Bug 需要版本、系统架构、安装方式、复现步骤、预期与实际结果、错误输出和最小示例；使用求助需要目标、卡住步骤和已做检查；功能建议需要使用场景、期望行为及当前方法的不足。所有模板要求替换密钥、凭据和个人路径。

维护者使用结构化标签表达以下状态：

- **待分类：** 新 Issue 尚未确认类型与材料；确认类型后离开。
- **等待信息：** 复现或判断所需材料缺失；提交者补齐后离开。
- **已确认：** 问题或目标已能复现和判断；分配实施时离开。
- **处理中：** 已有负责人和具体工作；修复或决定完成后离开。
- **已解决或已关闭：** 已提供适用版本/操作步骤并确认，或写明无法复现、范围外、重复等关闭理由。

维护者应在追问中列出具体缺口。提交者补充后应重新分类。关联修复的 PR 必须引用 Issue；合并或给出可执行解决方案后，维护者记录版本与验证方法再关闭。
