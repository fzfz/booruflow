# 资源关系与维护

管理首页提供九个入口。作品包含角色；角色可以保存别名、提示词和图片。画风保存描述、提示词、底模关系和图片。Prompt Tag 保存规范标签、别名、类别和图片。底模是模型、LoRA、画风和模板的分类基础；模型关联一个底模；LoRA 关联底模与模型，并保存触发词、默认权重、说明和图片。画师串保存可复用的画师提示词，并可关联画风。ComfyUI 实例保存服务连接；模板保存 Workflow JSON、底模和运行参数，并可独立于实例存在。

推荐维护顺序为底模、作品、角色与画风、Prompt Tag、模型、LoRA、画师串、ComfyUI 实例和模板。进入对应页面后用筛选和搜索确认目标记录，再新增或打开详情编辑。保存后重新搜索并核对字段。图片管理支持添加、查看、排序、设封面和删除；保存后确认卡片封面与详情顺序一致。

模型与 LoRA 条目只保存目录元数据，不上传模型权重。ComfyUI 实例凭据留在当前环境。删除前阅读页面给出的引用和影响；存在关联时先处理关联对象。批量迁移资源请使用[数据迁移](data-transfer.md)。
