# Issue 運用

Bug、サポート、機能提案の四言語テンプレートがあります。Bug は版、環境、導入、再現、期待/実際、出力、最小例、サポートは目的、停止手順、確認済み事項、機能は利用場面、期待動作、現方法の不足を記入します。秘密と個人パスは置換します。

状態は「分類待ち」「情報待ち」「確認済み」「対応中」「解決/終了」です。新規は分類待ち、必要資料が欠ければ情報待ち、再現・判断可能なら確認済み、担当と作業があれば対応中、版または手順が確認された場合や重複・範囲外理由が記録された場合は終了です。

質問では不足している情報を列挙し、回答後に状態を再判定します。修正 PR は Issue を参照し、マージまたは実行可能な解決手順の提示後に、対象バージョンと検証方法を記録します。
