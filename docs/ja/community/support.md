# サポート

まず `check` と `status` の結果、[トラブルシューティング](../user/troubleshooting.md)、[既存の Issue](https://github.com/fzfz/booruflow/issues) を確認します。同じ問題が登録済みであれば、対象バージョンと再現条件の差分を追記します。

新規ならサポートまたは Bug を選び、BooruFlow 版、OS/CPU、導入方法、目的、停止した手順、コマンドまたは画面、実出力、試した確認、最小再現データを示します。API キー、ComfyUI 資格情報、個人パス、私的内容は例に置換します。

保守者は再現と資料を確認し、不足項目を具体的に求めます。追加後に状態を再判定します。解決策は対象版または手順を示し、報告者が再試験します。修正確認、必要資料の長期不足、範囲判断の後、理由を記録して閉じます。
