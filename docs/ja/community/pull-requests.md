# Pull Request

問題、変更後動作、関連 Issue、範囲、検証コマンドと結果を記載します。UI は実画像、設定・構造・利用手順は四言語文書を更新します。任意の対応言語テンプレートを使えます。

自動検査の問題を先に解決します。保守者は範囲、Issue、検証結果を確認してから実装を確認します。新しい動作は正常、異常、境界の各条件をテストし、Schema、OpenAPI、エラー、移行、スクリプトは対応する契約テストとプラットフォーム検査を通します。指摘には、追加のコミットと再テストの結果で応答します。

範囲の明確化、契約との一致、必須テストの成功、文書の同期、画像または運用の検証結果、指摘の解決がマージ条件です。不足項目は具体的に列挙し、補完後に再確認します。
