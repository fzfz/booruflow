# 変更履歴

## v0.88.0（2026-09-14）

- 作品、キャラクター、画風、Prompt Tag、モデル、LoRA、アーティストプロンプト列、ComfyUI リソースを管理する BooruFlow を初めて公開しました。
- Windows と macOS でインストール、検査、起動停止、更新、バックアップ、復元、エクスポート、梱包、一回限りのインポートを行うネイティブスクリプトを追加しました。
- Embedding と Reranker の設定を必須とし、1,024 次元ベクトルを同期生成し、失敗時にバッチ全体をロールバックする空データベース向けインポートを追加しました。
- 中国語、英語、日本語、スペイン語の完全な文書と GitHub template を追加。

[v0.88.0 Release](https://github.com/fzfz/booruflow/releases/tag/v0.88.0) と [MIT License](../../LICENSE) を参照してください。
