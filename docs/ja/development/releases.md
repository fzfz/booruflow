# リリース

SemVer と接頭辞 `v` を付けたタグを使い、`config/release/` の構造化情報をインストーラー、更新処理、README、リリース添付物に共通する情報源とします。

パッケージのバージョン、四言語の変更履歴、移行と復旧の境界を更新します。契約テスト、単体テスト、結合テスト、E2E テスト、リンク、プラットフォーム用スクリプトを確認します。実際に検証した Windows と macOS のアーキテクチャだけを対応対象として記載し、タグ、パッケージ、データベースの対応範囲、データ形式を一致させます。

リリースには、単独で使用できる `install.bat` と `install.sh`、四言語のリリースノート、インストール手順、検証済みプラットフォーム、復旧手順へのリンクを添えます。公開後に新しいディレクトリへリポジトリを複製し、ダウンロード、インストール、設定、起動、状態確認、停止、同一バージョン間のエクスポートとインポートを確認します。

更新に失敗した場合は、バックアップと旧バージョンの識別情報を保持し、対応するコード、データベース、メディア、設定を復元します。復元後に検査、起動、バージョン、リソースを確認し、復元成功を記録してから修正版のリリースを準備します。v0.88.0 が新しい公開リポジトリの履歴開始点です。
