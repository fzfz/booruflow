# クイックスタート

[インストール](installation.md)と[設定](configuration.md)の後、手動作成またはデータ取込を選びます。

手動で作成する場合は `start.bat` または `bash start.sh` を実行し、表示された公開 URL を開きます。管理ホームでベースモデルを先に作成し、作品、キャラクター、画風を追加します。モデルはベースモデルに関連付け、LoRA はベースモデルとモデルに関連付けます。各ページで検索し、詳細と画像を確認します。

サンプルパッケージまたは別の v0.88.0 からデータを取り込む場合は、停止状態で次を実行します。v0.87.0 のデータは、先に[更新と復旧](update-recovery.md#新しい-v0880-へデータを移す)の手順で分離したコピーを移行 040 まで更新し、v0.88.0 のスクリプトでエクスポートします。

```bash
bash data-import.sh --input /path/to/package.tar.gz --check
bash data-import.sh --input /path/to/package.tar.gz --apply
bash start.sh
```

Windows は同名の `.bat` ファイルを使います。初期化済みで業務データがないデータベースだけを受け入れ、6 種類の 1,024 次元ベクトルを同期生成します。成功後に起動し、名称検索、詳細、画像、カバー、関連を確認します。終了コードが 0 で、状態表示が稼働中となり、管理画面が表示されれば初回利用は完了です。
