# リソース管理

管理ホームには 9 つの入口があります。作品はキャラクターを含み、キャラクターは別名、プロンプト、画像を持ちます。画風は説明、プロンプト、ベースモデルとの関連、画像を持ちます。Prompt Tag は標準タグ、別名、分類、画像を持ちます。ベースモデルはモデル、LoRA、画風、テンプレートを分類する基準であり、各モデルは 1 つのベースモデルに所属します。LoRA はベースモデルとモデルに結び付き、トリガー、既定の重み、説明、画像を持ちます。アーティストプロンプト列は画風と関連付けることができます。ComfyUI インスタンスは接続情報を保存します。テンプレートは Workflow JSON、ベースモデル、実行パラメーターを保存し、インスタンスから独立して存在できます。

ベースモデル、作品・キャラクター・画風、Prompt Tag、モデル、LoRA、アーティストプロンプト列、インスタンス、テンプレートの順に登録すると、関連を設定しやすくなります。作成前に検索し、保存後に再検索して値を確認します。画像は追加、表示、並べ替え、カバー指定、削除ができ、カードと詳細画面で順序を確認します。

モデルと LoRA はメタデータのみで重みファイルを保存しません。ComfyUI 資格情報はローカル環境に残ります。削除前に関連と影響を読み、依存先を先に処理します。一括移行は[データ移行](data-transfer.md)を使います。
