# データ移行

本文のルート直下のコマンドは公開済み v0.88.0 用です。現在のソースの `bin/` パスは次を参照してください： [スクリプトの配置と保守コマンド](../development/scripts.md).

アプリを停止し、新規ディレクトリへ出力して梱包します。

```bash
bash data-export.sh --output /path/to/export-dir
bash data-pack.sh --input /path/to/export-dir --output /path/to/booruflow-data.tar.gz
```

`--include-instances` は ComfyUI の名前と URL だけを含め、取り込み後のインスタンスを無効かつ設定待ちの状態にします。パッケージには、作品、キャラクター、画風、Prompt Tag、ベースモデル、モデル、LoRA、アーティストプロンプト列、関連、テンプレート、Workflow JSON、メディアを含めます。重み、セッション、履歴、ログ、絶対パス、認証情報は含めません。

対象データベースには現行の構造が必要です。業務データ、関連、画像、ベクトル、KNN の対象テーブルはすべて 0 件である必要があります。移行履歴と初期状態の `vector_spaces` は存在できます。[設定](configuration.md)に従って Embedding と Reranker のアドレス、モデル名、認証情報を設定してから実行します。

```bash
bash data-import.sh --input /path/to/booruflow-data.tar.gz --check
bash data-import.sh --input /path/to/booruflow-data.tar.gz --apply
```

`--check` は空のデータベース、設定、形式、バージョン、パス、メディア、参照を検査し、データを書き込みません。`--apply` は空であることを再確認し、既存の検索規則に従って 1,024 次元ベクトルを同期生成します。無効な作品、無効なキャラクター、所属作品が無効なキャラクターについては業務記録を保持しますが、検索可能なベクトル集合には追加しません。作品、キャラクター、画風、Prompt Tag、LoRA、アーティストプロンプト列のうち、それ以外の通常検索できる記録にはベクトルを生成します。その後、業務記録、メディア、ベクトル、KNN インデックスを 1 つのバッチとして確定します。確定前に失敗した場合は、そのバッチのデータベースへの書き込みを取り消し、バッチのファイルを削除します。検査またはベクトル準備で失敗した場合、および確定前の失敗後にロールバックと後片付けが完了した場合は、報告された問題を修正して検査と完全なインポートを再実行します。バッチ ID の出力後に処理が中断した場合、または後片付けに失敗した場合に限り、その ID を指定して `bash data-import.sh --recover --batch ID` を実行します。復旧処理は未確定バッチを取り消します。確定済みバッチの場合はインポートしたデータを保持し、一時ファイルを削除します。Windows は対応する `.bat` ファイルを使います。

1 件でもあれば表名と件数を示して拒否します。成功後の再取込も拒否されます。v0.88.0 同士と Windows/macOS 間を対象とします。未知の形式、より新しいデータベース、対応範囲外のバージョンは書き込み前に終了するため、そのパッケージに一致する BooruFlow バージョンを使用します。
