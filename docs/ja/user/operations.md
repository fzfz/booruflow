# 運用

本文のルート直下のコマンドは公開済み v0.88.0 用です。現在のソースの `bin/` パスは次を参照してください： [スクリプトの配置と保守コマンド](../development/scripts.md).

各スクリプトは自身の場所からインストール先を特定します。Windows は `.bat`、macOS は `bash name.sh` を使います。

- `start`: Node/npm、依存、設定、ポートを確認し、見える端末で起動して URL とログ場所を表示します。
- `status`: このインストール環境のプロセス、ポート、URL を表示します。
- `stop`: このインストールだけに正常終了を要求し、HTTP と SQLite の終了を待ちます。
- `check`: バージョン、権限、設定、ポート、tar、SQLite 拡張、データベースの状態を検査します。
- `backup` / `restore`: 停止中に、対応するデータベース、メディア、清掃キュー、設定を処理します。

Ctrl+C を押した後は、終了メッセージを待ちます。二重起動、ポート競合、終了のタイムアウトが発生した場合、スクリプトは対象を示して 0 以外の終了コードを返します。ログは既定で `data/diagnostics/` にあります。`.env` の変更後は再起動し、`check` と `status` の結果を確認します。Issue に添付する前に、認証情報と個人用パスを例示値へ置き換えます。
