All notable changes to the public BooruFlow repository are recorded here.

## [0.88.0] - 2026-09-14

- Published BooruFlow as a local catalog for works, characters, styles, Prompt Tags, generation models, LoRAs, artist prompt strings, and ComfyUI resources.
- Added native Windows and macOS installation, lifecycle, update, backup, restore, export, package, and one-time import commands.
- Added an empty-database data package import that requires configured embedding and reranker services, creates 1,024-dimensional vectors synchronously, and rolls back the batch on failure.
- Added complete Simplified Chinese, English, Japanese, and Spanish documentation and GitHub contribution templates.
