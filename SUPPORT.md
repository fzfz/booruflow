# BooruFlow support

[简体中文](docs/zh-CN/community/support.md) · [English](docs/en/community/support.md) · [日本語](docs/ja/community/support.md) · [Español](docs/es/community/support.md)

Start with the troubleshooting guide for your language. Search existing issues before opening a new one. Include BooruFlow version, operating system and CPU architecture, installation method, the command or page that failed, exact output, and the checks already tried. Replace API keys, credentials, and personal paths with example values.

Use a support request for setup or usage questions, a bug report for reproducible incorrect behavior, and a feature request for a proposed workflow change.
